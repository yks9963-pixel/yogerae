# 명령서: 전주 토지 임장 매물 블로그 초안 5편 + 경계선 이미지 프롬프트

## 0. 선행 확인 (하나라도 아니면 중단 후 보고)

1. 아래 "임장 확인값" 칸이 채워진 매물만 글을 쓴다. 빈 칸은 **추측으로 채우지 말고** 본문에서 해당 문장을 빼거나 `[임장 후 기재]`로 남긴다.
2. 각 매물의 **정확한 지번**이 확정됐는지 확인한다. 엑셀(11/2 추출본)에는 동 단위까지만 있다. 지번 미확정이면 광고 본문에 번지를 쓰지 않고 "덕진동1가 일대"처럼 동 단위로만 쓴다.
3. 각 매물의 **공동중개 동의** 여부(등록 중개사 허락)를 확인한다. 동의 없는 매물은 광고 글을 쓰지 않고 "동의 필요"로 보고한다.

## 2. 글쓰기 규칙

- 독자: 상가·토지 투자 검토자, 프랜차이즈 개발 담당자, 중개 파트너. 톤은 업계용 분석 + 홍보. 친근하되 과장 금지.
- 구성(편당): ① 한눈에 보는 요약 박스 ② 입지·접면 분석 ③ 면적·가격 분석(평당가는 "참고 계산치"라고 명시) ④ 활용 방향(용도지역이 확인된 범위 안에서만) ⑤ 계약 전 확인사항 ⑥ 문의 박스.
- 사실과 의견을 구분한다. 등록자 설명("개발지역", "공실 없음" 등)은 "등록자 기준"으로 쓰고, **임장에서 직접 확인한 것만 단정**한다.
- "최고", "최저", "무조건", "수익 보장", 개발 호재 단정 표현 금지. 천마지구 같은 개발계획은 고시·공고로 확인된 내용만 쓴다.
- 네이버 에디터에 붙일 수 있도록 일반 텍스트 + 구분선 형식으로 쓴다(별표 `**`, 표 마크다운 사용 금지). 소제목은 `POINT 01` 형식.
- 키워드: 전주토지, 전주토지매매, 전주상가부동산, 전주덕진구토지, 전주부동산, 전주위드공인중개사, 전주송천동토지 등. 매물 위치에 맞게 선택. 태그 10~15개.

## 4. 이미지: 경계선 위성지도

### 4-1. 먼저 알아둘 한계 (중요)

GPT 이미지 생성은 **실제 위성사진과 지적 경계를 정확히 만들지 못한다.** 위성사진처럼 보이는 이미지를 새로 "생성"하면 실제와 다른 가짜 지도가 되어 허위·과장 광고가 될 수 있다. 그래서 방식은 다음 두 가지로 제한한다.

- **방식 A (권장): 실제 지도 캡처 + GPT로 경계선만 표시.** 형이 네이버지도(위성+지적편집도) 또는 토지이음/브이월드에서 해당 필지를 캡처해 GPT에 업로드하고, 선과 글자만 얹게 한다.
- **방식 B: 개념도(일러스트).** 실제 사진이 아니라 "개략 배치도"로 명시하고 위성사진처럼 보이지 않게 만든다.

모든 이미지 하단에 반드시 넣을 문구: **"개략도 · 실제 경계는 지적도·측량 기준과 다를 수 있음"**

### 4-2. 공통 프롬프트 (방식 A, 매물마다 {} 부분만 교체)

```
첨부한 지도 캡처 이미지를 그대로 사용해 편집해 주세요. 배경 지도는 절대 새로 그리거나 바꾸지 말고, 아래 요소만 위에 덧그려 주세요.

1. 내가 표시해 둔(또는 지적선으로 보이는) 해당 필지의 경계를 빨간색 굵은 선(두께 4px, 반투명 빨강 채움 20%)으로 따라 그려 주세요. 경계를 임의로 넓히거나 다른 필지를 포함하지 마세요.
2. 필지 중앙에 흰 글씨 + 검은 외곽선으로 "{동·지목} · {면적}㎡ (약 {평수}평)" 표기.
3. 접한 도로 위에 도로명 라벨과 노란 화살표로 접면 방향을 표시: "{도로명} 접면".
4. 좌측 상단에 작은 박스로 "위드부동산중개사무소" 로고 텍스트만 표기.
5. 하단 중앙에 작은 회색 글씨로 "개략도 · 실제 경계는 지적도·측량 기준과 다를 수 있음".
6. 건물·나무·차량 등 이미지에 없던 것을 추가하거나 지우지 마세요. 해상도 유지, 정사각형 1080x1080.
수정한 부분이 위 6가지 외에 없는지 스스로 점검해 주세요.
```

### 4-5. 이미지 검수

- 업로드한 원본 캡처와 결과를 나란히 놓고, **경계 모양이 바뀌지 않았는지**, 없는 건물·도로가 생기지 않았는지 육안으로 확인한다. 다르면 사용하지 않는다.
- 위성사진 캡처는 지도 서비스 이용약관(출처 표기 등)을 확인한다. 네이버지도 캡처를 광고에 쓸 때의 허용 범위는 약관 기준이며, 이 명령서에서는 확인하지 못했다. 불확실하면 임장 때 직접 찍은 사진과 토지이음 지적도를 우선 사용한다.

## 5. 금지

- 블로그 게시·예약발행, 중개사 연락·메일 발송, 외부 서비스 업로드.
- 임장 확인값에 없는 사실(도로 폭, 용도지역, 개발계획, 임대수입 등)을 지어 쓰는 것.
- 위성사진을 AI로 새로 생성해 실제 사진처럼 쓰는 것.
- 타 중개사 매물의 등록자 연락처 노출.

## 6. 검증 (산출물마다)

- 글자수 1,800~3,000자(공백 포함), 별표·마크다운 기호 잔존 여부.
- 금액·면적·평당가를 본 명령서 표와 대조(평당가 재계산).
